# agent-autosuggest v0.3.0

**Released 2026-11-16. A minor release.** The agent's licence and open-source preparation, the bus
consumer bounded so a task is claimed only when a worker is free, and the image's bases pinned by
digest, since [v0.2.0](v0.2.0.md). The bounded bus changes behaviour a caller can see and adds
settings, which is why this is a minor release and not a patch. Image:
`docker.io/oramasearch/agent-autosuggest:v0.3.0`.

This release is the tree of `dev` after #35 (`24121d0`), with these notes and the version (#38).

### The licence — #36

agent-autosuggest is released under the MIT licence, copyright OramaSearch, Inc. (`LICENSE`,
`COPYRIGHT`). Every source file carries `SPDX-License-Identifier: MIT`, added and checked by
`tools/spdx-headers.py`. `THIRD_PARTY_LICENSES` lists the licence of every runtime dependency.
Contributions are made under `CLA.md` (contributors assign copyright to OramaSearch, Inc.),
following `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`. `tools/sbom.py` writes the software bill of
materials in SPDX 2.3 and CycloneDX, regenerated for this release.

### A security policy — #32

`SECURITY.md` says how to report a vulnerability privately and what we commit to in reply.

### A bus task is claimed only when a worker is free — #31

- Nothing is received while every worker is busy, so claimed tasks (and their credentials) no
  longer pile up in memory, and a task this replica cannot run stays unclaimed on the bus for
  another replica.
- `AGENT_BUS_WORKERS` (default 4) run at once; one customer holds at most
  `AGENT_BUS_TENANT_WORKERS` (default one fewer), and a freed worker goes to the waiting customer
  holding the fewest, so one tenant's burst cannot take every worker.
- At most 256 dispatch rows wait, never a claimed body. The receive uses the long poll's `wait_ms`.

### The image's bases are pinned by digest — #33

Each `FROM` and `COPY --from` names the multi-platform index digest its tag pointed to, so a later
build of the same source gets the same base. A new base is a reviewed change of the digest.

### Prepared for a public export — #35

Links to issues and pull requests, internal names, local paths and wording are removed from the
README, the docs and the earlier release notes. The agent files (`AGENTS.md`) ship with the
repository.

## Behaviour changes to know before it rolls

1. **The bus consumer runs at most `AGENT_BUS_WORKERS` turns at once** and leaves the rest on the
   bus, unclaimed.
2. **One customer holds at most `AGENT_BUS_TENANT_WORKERS` workers** while others wait.

## Settings it needs

No setting is required. Two optional settings are new, each with the default above:
`AGENT_BUS_WORKERS` and `AGENT_BUS_TENANT_WORKERS`. `git diff v0.2.0..v0.3.0 -- src` adds no other
environment read.

## Not included

- **Claiming tasks by reference and naming the task on every call** (#34, for lake#871): deferred
  for review, not in this release.
- Unchanged from [v0.2.0](v0.2.0.md#what-it-does-not-include) otherwise, except that bus
  back-pressure is now included.

## Known issues

Security-relevant first.

1. **The image bundles GPL and LGPL code** (#37): it is built on `python:3.12-slim` (Debian: glibc,
   bash, coreutils, dpkg, readline), so the image is not published. It moves to `scratch` with
   static binaries before it is.
2. **Library agents hold live task credentials for every tenant they serve**: one shared pod runs
   every tenant's turns with their task credentials.
3. **The workspace is not passed explicitly** (#11): the agent sends only `customer_id` on its
   reads, never the task's `workspace_id`.
4. **The lease is kept by activity only.** Lake renews a claim's lease on every capability call
   made with the task credential, so a turn is reclaimed only if one step outlasts `lease_seconds`.
   Not observed.
5. **The command line validates without workspace evidence** (#14).
6. **Corpus drafts fail validation**: the corpus's examples do not choose a registry level for S-1.
   The image keeps the `a882954` corpus.

Closed since v0.2.0: #23 (the bus claimed tasks before a worker was free), by #31.
